# Implementation Plan: Cross-Platform World Clock (Delta-T Zaman)

**Branch**: `001-tauri-world-clock` | **Date**: 2026-04-12 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-tauri-world-clock/spec.md`

## Summary

Build a cross-platform world clock utility using Tauri 2.10.3 that runs on macOS, Windows, Linux, iOS, and Android. The app displays multiple IANA timezones with real-time updates, solar-accurate day/night indicators, drag-and-drop reordering, scheduled alarms with native OS notifications, and system tray integration on desktop. Frontend built with vanilla TypeScript + Style Dictionary design tokens + plain CSS (zero framework); backend in Rust. All data stored locally (offline-first) via tauri-plugin-store. Full details in [research.md](./research.md).

## Technical Context

**Language/Version**: Rust stable >= 1.77.2 (backend) + TypeScript 5.x (frontend)
**Framework**: Tauri 2.10.3 + Vite (no frontend framework — vanilla TypeScript)
**Primary Dependencies**: Style Dictionary 4.x (build-time), SunCalc, tauri-plugin-notification 2.3.3, tauri-plugin-store 2.x, tauri-plugin-autostart 2.x, tauri-plugin-os 2.x, tauri-plugin-single-instance 2.x, tauri-plugin-positioner 2.x, tauri-plugin-updater 2.x, tauri-plugin-dialog 2.x, tauri-plugin-deep-link 2.x
**Storage**: tauri-plugin-store (JSON key-value: zones.dat, alarms.dat, preferences.dat)
**Testing**: Vitest (unit/DOM) + Playwright (E2E) + cargo test (Rust)
**Target Platform**: macOS (WKWebView), Windows (WebView2), Linux (WebKitGTK), iOS (WKWebView), Android (Chrome WebView)
**Project Type**: Desktop + mobile app (Tauri hybrid)
**Performance Goals**: Clock update <= 1ms DOM cost per tick, cold start < 2s (desktop) / < 3s (mobile), 30 simultaneous timezone cards at 1/sec update with no jank
**Constraints**: Offline-first (core features work without network; optional telemetry + auto-update use Cloudflare), < 15 MB install size, max 30 timezone entries, max 50 active alarms
**Scale/Scope**: Single-user utility app, ~28 TS modules (12 components, 10 services, 3 state, 3 types), ~12 Rust command files, 5 platform targets, 2 Cloudflare Workers (telemetry ingest, update manifest + tz data patches), 1 CI/CD pipeline (GitHub Actions)

## Project Structure

### Documentation (this feature)

specs/001-tauri-world-clock/ contains: plan.md (this file), research.md (R1-R22 decisions), data-model.md (entities + persistence), quickstart.md (dev setup), contracts/ipc-commands.md (IPC boundary), and tasks.md (generated by speckit.tasks).

### Source Code (repository root)

**Frontend** (src/): Vanilla TypeScript component modules in components/ (clock-card.ts, clock-list.ts, alarm-card.ts, alarm-list.ts, alarm-form.ts, timezone-search.ts, daynight-indicator.ts, settings.ts, about.ts, tray-preview.ts, export-import.ts, compact-view.ts). State management in state/ using a typed pub/sub event bus (clocks.ts, alarms.ts, preferences.ts, time.ts). Business logic in services/ (timezone-search.ts, alarm-scheduler.ts, daynight.ts, persistence.ts, ipc.ts, keyboard-shortcuts.ts, platform.ts, accessibility.ts, deep-link.ts, heartbeat.ts). Type definitions in types/ (timezone.ts, alarm.ts, preferences.ts). Bundled timezone data in data/timezones.json. UI strings in locales/ (en.json). Design tokens in tokens/ (base/, semantic/, component/, high-contrast/) processed by Style Dictionary into styles/tokens.css + styles/high-contrast.css. Root index.html with tab navigation, styles/main.css importing tokens.css, main.ts for mount + init.

**Backend** (src-tauri/): Rust commands in src/commands/ (system.rs, tray.rs, alarm.rs, window.rs, telemetry.rs, updater.rs, export.rs, platform.rs, tz_data.rs, deep_link.rs, heartbeat.rs). Tray setup in src/tray.rs. Plugin registration in src/lib.rs. Desktop entry in src/main.rs. Config in tauri.conf.json, permissions in capabilities/main.json.

**Infrastructure** (infra/): Cloudflare Worker scripts for telemetry ingestion (workers/telemetry/) and update manifest serving (workers/updater/). Wrangler configuration for deployment. R2 bucket for update binaries. Privacy policy source (privacy-policy.md → deployed to Cloudflare Pages).

**CI/CD** (.github/workflows/): release.yml — builds signed binaries for all 5 platforms via matrix strategy, runs tests, uploads desktop artifacts to Cloudflare R2, generates update manifest, and submits mobile artifacts to app store pipelines. ci.yml — runs lint, type-check, unit tests, and cargo test on every PR.

**Tests** (tests/): Unit tests (Vitest, pure logic), DOM tests (Vitest + jsdom), E2E tests (Playwright).

**Structure Decision**: Tauri standard dual-root layout (src/ for frontend, src-tauri/ for Rust backend). Tests under top-level tests/ directory. Design tokens under top-level tokens/ directory. Mirrors the official Tauri vanilla-ts template.
