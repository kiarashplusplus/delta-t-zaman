# Quickstart: Delta-T Zaman

**Branch**: `001-tauri-world-clock` | **Date**: 2026-04-12

## Prerequisites

| Tool | Required Version | Check Command |
|------|-----------------|---------------|
| Rust | stable ≥ 1.77.2 | `rustc --version` |
| Node.js | ≥ 18.x | `node --version` |
| npm | ≥ 9.x | `npm --version` |
| Xcode | ≥ 15 (macOS/iOS builds) | `xcode-select -p` |
| Android Studio | ≥ Hedgehog (Android builds) | Manual check |
| Tauri CLI | ≥ 2.10.3 | `cargo tauri --version` |

## Project Setup

```bash
# 1. Initialize Tauri project with vanilla TypeScript
npm create tauri-app@latest delta-t-zaman -- \
  --template vanilla-ts \
  --manager npm

cd delta-t-zaman

# 2. Install Tauri CLI
cargo install tauri-cli --version "^2.10"

# 3. Install frontend dependencies
npm install suncalc
npm install -D style-dictionary@4

# 4. Install Tauri plugins (Rust side — add to src-tauri/Cargo.toml)
# tauri-plugin-notification = "2"
# tauri-plugin-store = "2"
# tauri-plugin-autostart = "2"
# tauri-plugin-single-instance = "2"
# tauri-plugin-positioner = "2"
# tauri-plugin-os = "2"

# 5. Install Tauri plugins (JS side)
npm install @tauri-apps/plugin-notification \
            @tauri-apps/plugin-store \
            @tauri-apps/plugin-autostart \
            @tauri-apps/plugin-os

# 6. Initialize mobile targets
cargo tauri ios init    # Requires Xcode
cargo tauri android init  # Requires Android Studio
```

## Key Files to Create First

1. `tokens/base/color.json` — Design token primitives (colors, spacing)
2. `style-dictionary.config.json` — Build config to generate `src/styles/tokens.css`
3. `src/types/*.ts` — TypeScript type definitions (from data-model.md)
4. `src/data/timezones.json` — Bundled timezone metadata
5. `src/state/event-bus.ts` — Typed pub/sub event bus
6. `src/state/time.ts` — Real-time clock ticker
7. `src/components/clock-card.ts` — Core clock display component
8. `src-tauri/src/commands/system.rs` — System info IPC command
9. `src-tauri/capabilities/main.json` — Permission declarations

## Configuration Notes

### `tauri.conf.json` key settings
```json
{
  "productName": "Delta-T Zaman",
  "identifier": "com.deltat.zaman",
  "app": {
    "windows": [{
      "label": "main",
      "title": "Delta-T Zaman",
      "width": 420,
      "height": 680,
      "minWidth": 320,
      "minHeight": 480,
      "decorations": true,
      "transparent": false
    }],
    "security": {
      "csp": "default-src 'self'; style-src 'self' 'unsafe-inline'"
    }
  }
}
```

### Mobile-specific
- **iOS**: Add notification background mode to `Info.plist`
- **Android**: Add `SCHEDULE_EXACT_ALARM` permission to `AndroidManifest.xml`
- Both platforms: Request notification permission on first alarm creation
